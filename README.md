# Тестирование математической функциональности проекта

Данный проект содержит набор юнит-тестов, предназначенных для проверки корректности работы математических функций, реализованных на страницах `Page1`, `Page2` и `Page3`.

---

## Структура тестов

### 1. Тесты для `Page1` (`Funct1`)
- **`CalculateFunction_WithZeroValues_ReturnsExpectedResult`**  
  Проверяет работу функции при нулевых входных данных. Ожидается, что результат начинается с строки "3,4641".

- **`CalculateFunction_WithLargeValues_ReturnsInfinity`**  
  Проверяет реакцию функции на очень большие значения (`Infinity`). Ожидается, что результат содержит символ бесконечности.

- **`CalculateFunction_DivisionByZero_ReturnsInfinity`**  
  Проверяет обработку деления на ноль внутри функции. Ожидается, что результат содержит символ бесконечности (`∞`).

---

### 2. Тесты для `Page2` (`Funct2`)
- **`CalculatePiecewiseFunction_PositiveXAndY_ReturnsExpectedResult`**  
  Проверка метода при положительных значениях `X` и `Y`. В результате не должно быть ошибок или NaN.

---

### 3. Тесты для `Page3` (`Funct3`)
- **`TestCalculateWithValidInput`**  
  Проверка функции при валидных вводных данных. После вычислений должны появляться ожидаемые строки и точки данных для графика.

---

## Итог и рекомендации

- Данные тесты демонстрируют, что:
  - Реализованные функции правильно обрабатывают граничные случаи и ошибки.
  - Функционал страницы соответствует ожидаемым сценариям.
- Успех тестирования свидетельствует о корректной реализации методов, отсутствие ошибок — о стабильной работе.

---

## Возможные причины успешного / неуспешного выполнения тестов

- **Успешное выполнение:**  
  Методы реализованы правильно, все входные данные корректны, исключения и ошибки обработаны должным образом.

- **Неудачное выполнение:**  
  Причины — логические ошибки, неправильная обработка исключений или некорректные входные данные.
